# Project-Database-System-
A database project developed for a company of our choice based on the project requirement of this Data &amp; Information Management course. For this project, our group selected Lumut Naval Shipyard Sdn Bhd ( LUNAS ) as the company to develop the database system. Basically, this project focuses on designing a relational database system for Lumut Naval Shipyard ( LUNAS ) company, a Malaysian company that involved in shipbuilding, heavy engineering and maintenance, repair and overhaul ( MRO ) services. 
This project also includes an Enhanced Entity-Relationship Diagram ( EERD ), relational databes schemas, data specifications, data layouts, and relationship tables based on the requirements of this course.
